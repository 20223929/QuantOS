# QuantOS v0.1.0-alpha 发布验证清单

## 1. 后端验证

执行：

```bash
cd backend
pytest
```

检查：

- FastAPI启动正常
- Strategy Engine测试通过
- Backtest Engine测试通过
- Risk Engine测试通过
- Market模块测试通过

## 2. 前端验证

执行：

```bash
cd frontend
npm install
npm run build
```

检查：

- TypeScript编译通过
- React生产构建成功
- Dashboard页面正常加载

## 3. Docker验证

执行：

```bash
docker build -t quantos:0.1.0-alpha .

docker compose config
```

检查：

- backend镜像构建
- compose配置有效
- PostgreSQL/Redis服务定义正确

## 4. CI验证

GitHub Actions检查：

- backend-test
- frontend-test
- docker-build
- regression

## 5. 发布条件

全部通过后创建：

```
v0.1.0-alpha
```
